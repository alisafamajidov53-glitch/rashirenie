# Технический аудит ChannelPilot 0.16.3

Дата контрольной проверки: 26 июля 2026 года.

## Исправления логики

- Канальная метрика 60 минут/24 часа выбирает больший из двух независимо
  наблюдаемых приростов: общего публичного `viewCount` и суммы rolling-дельт
  конкретных видео. Источники никогда не складываются, поэтому запоздавшее
  обновление канала не считает один просмотр повторно.
- Снимки больше не округляются до начала минуты. Изменение `100 → 101` через
  несколько секунд сохраняется отдельной точкой и сразу даёт `+1`; неизменный
  счётчик по-прежнему записывает не больше одного heartbeat в минуту.
- Окна считаются относительно последнего успешного API-снимка. Компактная
  строка всегда подписана понятными периодами `60 мин` и `24 часа`, а
  фактическое покрытие доступно в подсказке и подробной аналитике. Число
  обнаруженных просмотров показывается до заполнения полного окна.
- 15-минутная динамика сравнивает скорость на минуту, а не сырые суммы окон
  разной длительности, и включается только при пяти минутах данных в каждом
  окне.
- Поздно завершившийся старый запрос больше не удаляет более свежую минуту.
- Кэш realtime больше не считается свежим 95 секунд. Видимая вкладка проверяет
  обновление каждые 30 секунд, а общий throttle защищает квоту от дублей между
  несколькими вкладками и минутным Chrome alarm.
- Временное снижение публичного счётчика не удваивает просмотры при
  восстановлении. Постоянная коррекция подтверждается пятью последовательными
  снимками; небольшая коррекция на многомиллионном канале больше не замораживает
  дальнейший рост.
- История наблюдений переведена на чистую схему V2. Потенциально загрязнённые
  старыми расчётами снимки не мигрируют в новые окна 60 минут/24 часа.
- Пустые календарные дни Analytics заполняются только внутри реально
  возвращённого диапазона; задержка YouTube Analytics не превращается в
  выдуманные нулевые дни.
- Таблица лидеров ранжирует все последние 50 видео, затем ограничивает вывод,
  а скорости 60 минут/24 часа нормализуются по фактическому времени наблюдения.
- Экспорт разделяет пришедших, ушедших и чистый прирост подписчиков и включает
  покрытие кратких realtime-окон.
- Нулевая предыдущая неделя больше не превращается в выдуманные `+100%`:
  интерфейс честно показывает отсутствие базы сравнения.

## Надёжность

- OAuth-запросы привязаны к Client ID и поколению сессии. Запоздавший silent
  OAuth больше не может восстановить токен после выхода или смены аккаунта.
- Проверка backend принимает оба официальных формата `tokeninfo`:
  `aud/sub` и `issued_to/user_id`, сохраняя обязательную проверку Client ID,
  YouTube scope и срока действия.
- Интерактивное переподключение действительно открывает выбор аккаунта, но
  закрытие окна не удаляет исправный предыдущий кэш.
- Cooldown Gemini/Groq/TwelveLabs хранится между контекстами расширения.
  Повторный запрос до окончания паузы не отправляется; Auto переключается на
  доступный резервный API. Генератор AI-превью использует ту же защиту квоты.
- Ошибка запрета конкретной модели отделена от ошибки API key.
- Автозахват Studio принимает только исходное видео и не подменяет результат
  выбранным позже служебным файлом.
- Локальное хранилище защищено от доступа content‑контекста, расширено для
  долговременных снимков и ограничено актуальным рабочим набором видео.

## Интерфейс и редактор

- Виджет встраивается после цельной поисковой секции Studio/YouTube, а не
  между системными кнопками. Нативный flex-spacer резервирует место в шапке, а
  визуальный слой позиционируется поверх него вне `overflow`-контейнера
  YouTube, поэтому верх или низ панели больше не срезается. Во время замены
  шапки работает компактный плавающий fallback.
- Неопределённый `—` в нижней строке заменён различимыми состояниями:
  `…` — загрузка, `↻` — требуется Google, `!` — данные временно недоступны.
- Вставка верхнего spacer и нативных AI-карточек повторно проверяет родителя
  непосредственно перед DOM-операцией. Если Studio заменил дерево в этот
  момент, операция безопасно отменяется и повторяется на новом SPA-дереве,
  не создавая необработанный `DOMException` в списке ошибок расширения.
- Добавлены отдельные состояния накопления, stale-снимка и повторной
  авторизации; неподтверждённые данные не помечаются как «стабильные».
- Повышена минимальная читаемость popup, Studio-карточек и внутреннего кабинета;
  добавлены видимый keyboard focus и `prefers-reduced-motion`.
- Редактор блокирует экспорт до декодирования исходного кадра, предлагает более
  плотную ленту кадров, точный таймкод, 16:9/9:16 и генерацию AI-фона 1K/2K/4K.
- Техническое имя загружаемого файла распознаётся как пустой заголовок, чтобы
  мультимодальный анализ опирался на реальное содержимое.

## Контрольный результат

- 9 test files / 53 unit tests;
- direct AI integration smoke, включая cleanup, fallback и cooldown;
- strict typecheck shared/extension/API;
- production build расширения и backend;
- `npm audit --omit=dev`: 0 известных уязвимостей.

## Ограничение источника

Публичные YouTube API не отдают тот же закрытый поминутный realtime-отчёт,
который отображает YouTube Studio. ChannelPilot показывает максимум
наблюдаемой дельты официального канального `viewCount` и безопасной суммы
дельт последних видео. Обновления могут приходить пакетно и не обязаны
совпадать со Studio до единицы. Интерфейс явно показывает источник, покрытие и
время последнего успешного снимка.
