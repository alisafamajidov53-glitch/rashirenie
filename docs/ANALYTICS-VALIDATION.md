# Проверка расширенной аналитики

## Автоматические проверки

`npm run check` запускает lint, форматирование, проверку типов, тесты и production-сборку.

`npm run test:ui -w @channelpilot/extension` отдельно проверяет реальные React-компоненты с имитацией Chrome API и ответы YouTube через mock fetch:

- равные календарные периоды, неполную историю и нулевую процентную базу;
- фильтры подтверждённых форматов, отсутствие Analytics и точность сводки;
- загрузку окна видео, повтор после ошибки, закрытие и частично доступные метрики;
- фильтр выбранного видео в истории, fallback, engaged views и источниках трафика;
- истёкшую авторизацию и отмену запроса;
- восстановление верхнего виджета после fullscreen, замены шапки и SPA-перехода;
- сохранение последнего снимка при offline и выход из аккаунта.

## Изолированный визуальный preview

Из `apps/extension`: `npx vite --config test/preview.config.ts`.

Открыть `http://127.0.0.1:5174/test/preview.html`. Здесь только тестовые данные и mock Chrome API; они не являются статистикой подключённого канала. Preview не изменяет production-сборку и не содержит реальные ключи.

Проверять desktop, tablet и mobile, обе темы, клавиатуру и отсутствие горизонтального переполнения. Окно видео открывается нажатием на его название.

## Перед выпуском: живой канал

Автотесты и preview не заменяют проверку реального расширения с авторизованным YouTube:

- [ ] Перезагрузить расширение и принудительно обновить Analytics.
- [ ] Сверить даты, историю и источники выбранного видео с YouTube Studio.
- [ ] Проверить Shorts, обычные видео и видео с неопределённым форматом.
- [ ] Проверить возврат виджета после настоящего fullscreen на youtube.com.
- [ ] Проверить offline, истечение авторизации и выход во время загрузки.

Тип контента берётся из `creatorContentType`, не из длительности. Сравнение видео относится к одному 28-дневному отчётному окну, но не к одинаковому возрасту публикаций. Отсутствующие метрики не должны отображаться как нули.
