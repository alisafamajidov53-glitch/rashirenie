# Основные пользовательские сценарии

## 1. Первое подключение

1. Пользователь открывает настройки ChannelPilot и копирует redirect URI.
2. Создаёт Google OAuth Client ID типа «Веб-приложение», добавляет redirect URI
   и вставляет Client ID в расширение.
3. Вводит Gemini, TwelveLabs и/или Groq keys, выбирает модели и режим одного
   API, Auto или «Gemini + Groq». При необходимости обновляет список моделей.
4. Нажимает «Войти через Google».
5. Chrome показывает consent screen с read-only scopes.
6. Расширение загружает канал, последние ролики и историю аналитики.
7. Фоновый service worker начинает минутное наблюдение за новыми публикациями.

Google OAuth и загрузка аналитики считаются двумя отдельными этапами. Если
первый запрос YouTube API временно не выполнен, аккаунт остаётся подключённым,
а интерфейс показывает точную причину и кнопку повторной синхронизации.

Успешный результат: закреплённый виджет в YouTube и Studio отображает состояние
канала, а через час доступно полное наблюдаемое окно «60 минут».

После истечения access token расширение сначала обновляет его без окна. Если
Google требует взаимодействия, подключение и последний снимок аналитики
сохраняются, а интерфейс показывает «Обновить Google-сессию» вместо ложного
выхода из аккаунта.

## 2. Оптимизация во время загрузки

1. Пользователь загружает видео в YouTube Studio.
2. Content script обнаруживает выбранный видеофайл через change/input,
   drag-and-drop или сканирование скрытого file-input и сразу запускает
   мультимодальный анализ. Вводить заголовок необязательно.
3. При вводе заголовка или описания ChannelPilot ждёт 1,4 секунды после
   последнего символа и запускает обновлённый текстовый анализ. Пока идёт
   полный анализ файла, текстовый debounce не может перезаписать его результат;
   последующие правки используют проверенные выводы из видео.
4. Под полем заголовка появляется блок минимум с десятью вариантами выбранной
   стратегии и кнопками копирования/предпросмотра.
5. Под описанием поочерёдно появляются отдельные карточки описания, тегов,
   хэштегов, ключей, идей обложки и SEO-рекомендаций.
6. В Auto сначала работает Gemini; при квоте или сбое целое видео переходит в
   TwelveLabs Pegasus, затем при необходимости в Groq. В режиме
   «Gemini + Groq» Groq параллельно делает транскрипцию и второй SEO-разбор.
7. Карточка показывает текущий этап: загрузку, обработку сцен, транскрипцию,
   анализ или переключение резервного API, поэтому длинный запрос не выглядит
   зависшим.
8. Перед заменой заголовка или описания ChannelPilot показывает старое и новое
   значение в модальном окне. Запись в поле Studio происходит только после
   явного подтверждения; остальные данные можно безопасно скопировать.
9. AI возвращает 3–5 кадров с таймкодом и оценкой 0–100. Расширение локально
   извлекает три лучших доступных кадра, накладывает AI-заголовки и предлагает
   скачать готовые JPG 1280×720 для дальнейшей доработки превью.

## 3. Быстрый анализ без файла

1. На любой странице YouTube пользователь открывает панель.
2. Вводит тему, текущий title, description или transcript.
3. Groq/Gemini генерирует structured result.
4. При отсутствии ключей работает локальный эвристический fallback — удобно
   для проверки UI, но это не замена AI.

## 4. Контроль после публикации

1. Пользователь открывает обычный YouTube или любую страницу YouTube Studio.
2. Компактная верхняя строка показывает просмотры за 60 минут, 24/48 часов и
   всё время, являясь частью шапки рядом с поиском, а не слоем поверх него.
3. При необходимости пользователь раскрывает виджет и нажимает «Скрыть» либо
   отдельно скрывает кнопку ChannelPilot AI. Оба элемента возвращаются через
   popup расширения без переустановки.
4. Рейтинг «Набирают сейчас» сортирует видео по выбранному периоду и показывает
   ускорение последних 15 минут, engagement rate и прогноз 24 часов.
5. Виджет обновляется каждую минуту; по клику открывается подробная аналитика
   7/14/28 дней с удержанием, watch time, shares и чистым приростом подписчиков.
6. Пользователь переходит из строки видео в его Analytics в Studio.
7. Через 24–48 часов сравнивает CTR/удержание вручную и повторно улучшает
   metadata на основе рекомендаций.

## 5. Ошибки и деградация

- Нет Google-сессии → понятный sign-in screen.
- Нет канала → сообщение «канал не найден».
- AI provider недоступен → расширение показывает понятную ошибку; в режиме
  «Gemini + Groq» сохраняется успешный ответ второго провайдера. Эвристический
  `local-fallback` доступен в опциональном backend, но не выдаётся за AI-анализ
  внутри расширения.
- Gemini вернул `429 RESOURCE_EXHAUSTED` → в режиме Auto видео сразу
  продолжает через TwelveLabs, затем при необходимости через Groq, и показывает
  заметную плашку о переключении. Если резервов нет, учитывается
  `Retry-After`/`RetryInfo` и выполняется одна отложенная попытка; бесконечных
  повторов нет.
- TwelveLabs asset не обработался или анализ завершился ошибкой → временный
  asset удаляется, а Auto переходит к следующему доступному провайдеру.
- Ошибка AI показывается один раз под заголовком и всегда локализуется по языку
  интерфейса. Пользователь может сразу повторить анализ, включить Auto при
  подключённом TwelveLabs/Groq или открыть настройки API; номер версии виден в
  карточке.
- Стек с хешем старого `assets/index.tsx-*.js` после обновления расширения →
  полностью перезагрузить или заново открыть вкладку Studio, чтобы Chrome
  внедрил актуальный content script.
- Media через опциональный backend превышает 100 МБ → 413 и рекомендация
  использовать прямой режим extension, меньший файл или production job pipeline.
- DOM Studio изменился → значение копируется в clipboard вместо тихой потери.

## 6. Внутренний кабинет расширения

1. Пользователь открывает «Настройки» расширения.
2. Страница `src/options/index.html` показывает обзор канала с периодами
   60 минут, 24 часа и всё время.
3. В разделе «Видео и рост» ролики сортируются по выбранному периоду; доступны
   скорость, тренд, engagement rate, AI-анализ и переход в Studio.
4. В AI Studio пользователь выбирает видео или вводит тему, стратегию и тон,
   затем получает минимум 10 заголовков, описания, теги, идеи превью, pinned
   comment, сценарный план и идеи Shorts.
5. В меню «Экспорт» скачивает полный JSON-снимок, CSV по видео, CSV истории
   за 28 дней либо отдельный JSON последнего AI-разбора.

## 7. Редактор превью

1. Пользователь загружает изображение или видео либо отправляет текущее превью
   из таблицы аналитики.
2. Выбирает формат YouTube 16:9 или Shorts 9:16.
3. Для видео выбирает нужный кадр; затем редактирует два текстовых слоя,
   положение, цвета, масштаб, виньетку, фон, обводку и коррекцию изображения.
4. Безопасные зоны показывают области интерфейса YouTube и Shorts; кадры можно
   выбирать лентой, таймкодом или клавишами ←/→.
5. Из AI Studio пользователь может нажать «Открыть кадр»: тот же исходный
   видеофайл откроется в редакторе сразу на рекомендованном таймкоде.
6. При необходимости Gemini Image создаёт новый фон по брифу и текущему
   кадру-референсу; надписи остаются редактируемыми локальными слоями.
7. Готовое превью скачивается как JPG или PNG в целевом разрешении.

## 8. Аналитика подписчиков

1. ChannelPilot получает общие `subscribersGained` и `subscribersLost` за
   последние 28 полных дней.
2. Отдельные пакетные отчёты с dimension `video` связывают подписки и отписки
   со страницами просмотра последних 50 видео.
3. Кабинет и Studio-виджет показывают пришло, ушло, чистый прирост и количество
   подписок на 1 000 просмотров для каждого видео.

## 9. Исследование конкурентов

1. Пользователь добавляет URL, handle или ID публичного YouTube-канала.
2. Service worker разрешает канал через YouTube Data API, загружает публичные
   uploads и статистику без scraping.
3. Раздел показывает медиану/среднее просмотров, частоту публикаций, длительность
   и последние успешные темы; результат кэшируется для экономии квоты.
4. Канал сохраняется в workspace и может быть удалён пользователем.

## 10. Идеи и контент-план

1. Idea Generator создаёт пакет из 10 идей по теме, выбранному формату и данным
   канала. Оценка помечена как AI packaging score, а не прогноз спроса.
2. Пользователь сохраняет идею в планер, задаёт дату, статус и заметки.
3. Карточки перемещаются drag-and-drop между идеей, черновиком, запланированным,
   готовым и опубликованным состояниями.
4. Поиск и фильтры работают локально; план импортируется/экспортируется в JSON
   или CSV. При включённых уведомлениях alarm напоминает о близкой публикации.

## 11. Помощник по комментариям

1. Пользователь выбирает видео; комментарии загружаются через
   `commentThreads.list` по ключу YouTube Data API из раздела «Подключения».
   Read-only OAuth этот метод не принимает (нужен scope `youtube.force-ssl` с
   правом записи), поэтому расширение не расширяет доступ к каналу, а читает
   публичные комментарии по ключу. Без ключа страница объясняет, как его создать.
2. Локальная классификация выделяет вопросы, тональность и вероятный spam.
3. AI создаёт только черновик ответа выбранного тона.
4. Пользователь копирует ответ или открывает комментарий на YouTube и публикует
   его самостоятельно; автоматической отправки нет.

## 12. SEO и Performance Score

1. Для видео рассчитывается детерминированный балл по доступным факторам:
   наблюдаемой скорости, вовлечённости, удержанию, подпискам, lifetime pace и
   watch time.
2. Каждый фактор показывает источник, значение, вес и причину; недоступные
   факторы исключаются из знаменателя.
3. SEO-чеклист проверяет только известные метаданные. Playlist, cards, end
   screens и pinned status помечаются неизвестными, поскольку read-only API не
   подтверждает их состояние.

## 13. Приватность медиа

1. Автоотправка изображения, аудио или видео в Gemini/TwelveLabs/Groq выключена
   по умолчанию.
2. Пользователь включает её отдельным переключателем Privacy и видит, какие
   провайдеры могут получить файл.
3. После отключения content script продолжает локальный анализ и не начинает
   новые media-запросы.
